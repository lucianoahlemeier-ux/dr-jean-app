# Reference — Annotated Report Structure (the gold standard)

This is the *shape* of a great report, abstracted from a real one so the builder can match
structure and voice. (The original full report stays with the owner; the problematic content
in any given chat is handled per the "harmful content" rule in `docs/03` — named as the one
serious note, never amplified.)

Read this as the target `{{PERSONA_NAME}}` output should hit.

---

**[Title]** — one funny sentence that is the verdict.
> e.g. a metaphor-as-headline that sums the whole relationship in a joke.

**[Byline]** — one line: who the persona is + one absurd humanizing detail.

**[Privacy line]** — "the conversation used to write this wasn't saved."

**[Cold open]** — proves it read everything by citing the exact count ("I read all 4,182 of
these"), establishes voice: confident, funny, "I have notes. I have feelings. I have a
diagnosis."

**[The central metaphor]** — ONE image the whole piece hangs on (in the source: "a band
that's been in the studio for months and never released a song"). Everything ties back to it.

**[roles you think you play vs the roles you actually play]** — a direct contrast: the
flattering self-image, then the funnier/truer reality for each person. Built on real quotes.

**[a tender beat]** — one sincere, disarming observation that shifts the register from roast
to affection.

**[the central tension]** — the LONGEST section. The recurring conflict, reconstructed from
**verbatim quotes with dates**. Shows a pattern the people themselves half-know but haven't
said out loud. This is the emotional core.

**[the leaderboard]** — "who's winning at: [dimension]" — a list of playful head-to-head
verdicts (building things / vision / excuses / punctuality …), each one line, each specific.

**[the star review]** — ⭐ ratings on 5–7 invented dimensions (ambition, comedic chemistry,
loyalty, execution, follow-through, punctuality…), each with a one-line justification and a
real quote. Ends with an overall score + a one-liner.

**[the glossary / dialect decode]** — the group's in-jokes, acronyms, and slang, defined
funnily ("for the historians"). This is pure specificity and highly shareable.

**[what you're doing right that you can't see]** — warm and sincere: the real strength of the
relationship.

**[what you're doing wrong that nobody loves you enough to say]** — honest; contains the
**single serious note**, explicitly flagged as the one serious thing.

**[Callback closer]** — signs off echoing a running in-joke from the chat.

---

## What to copy (the transferable DNA)
- Verbatim quotes + dates in every major section.
- The comedy → tenderness → one-serious-note → warm-callback arc.
- Named, lowercase, bit-like section headers.
- Semi-templated scaffolds (leaderboard / star review / glossary) that force personalization
  while keeping output consistent across chats.
- Ends making people feel *seen*.
