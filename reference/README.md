# reference/

Material the builder uses:

- **`Site/`** — screenshots of the whole website (landing page incl. the reaction/"wall of
  love" strip, the report page, overall look). Match the design + aesthetic to these. See
  `docs/05_DESIGN.md`.
- **`beginning questions/`** — screenshots of the ~11 onboarding steps ("Get the Report"
  flow), in any order/filenames. The builder should open each image, read it, and infer the
  correct sequence, then reproduce the flow. See `docs/01_PRODUCT_AND_FLOW.md`.
- **`report_structure_annotated.md`** — the target structure + voice for the report output.
  See `docs/03_REPORT_AND_PERSONA.md`.
